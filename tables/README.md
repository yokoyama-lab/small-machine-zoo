# Tables of the seven new URTMs

Plain-text quintuple tables of the seven new universal reversible Turing machines
of the paper. This file is the only description of them; each table file has a
single comment line that names the machine.

## Format

After the comment line (`%`), a file gives the initial state, the final states
(none), the states, the symbols, the blank, and one quintuple `[p, s, t, d, q]` per
line: in state `p` reading `s`, write `t`, move `d` (`-` left, `+` right), and enter
`q`. There are no halting quintuples; a machine halts where no quintuple applies.

|---|---|---|---|
| `urtm3-600.txt` | URTM(3,600) | 1,572 | Section 3.4 |
| `urtm4-41.txt` | URTM(4,41) | 142 | Section 3.3, Table 4 |
| `urtm5-37.txt` | URTM(5,37) | 145 | Section 3.3, Table 4 |
| `urtm6-30.txt` | URTM(6,30) | 160 | Section 3.3, Table 4 |
| `urtm7-28.txt` | URTM(7,28) | 160 | Section 3.3, Table 4 |
| `urtm8-21.txt` | URTM(8,21) | 149 | Section 3.3, Table 4 |
| `urtm85-2.txt` | URTM(85,2) | 153 | Section 3.5 |

The tables are generated by the same tools and from the same construction
parameters as the tables in the Lean formalization. The paper does not print these
tables; this directory is where they are published.

## URTM(3,600)

Obtained from Morita's URTM(32,3) by the three-state conversion of the paper (one
symbol per cell, shared and pruned counters, mirrored). The states are `l`, `r0`,
`r1`; the initial state is `l`; the blank is `b`.

## The five machines obtained by symbol merging

URTM(4,41), URTM(5,37), URTM(6,30), URTM(7,28), and URTM(8,21) are obtained from
Morita's URTM(13,7) by block decomposition with `(b+,b-)` blocks, merging of roles,
and symbol merging (Section 3.3 of the paper). They are given without their two
halting quintuples; the formalization proves universality for this form as well
(Section 4 of the paper).

- Symbols: `b`, `y`, `n`, `y1`, `n1`, `*`, `$` are the symbols of URTM(13,7) (`y1`
  and `n1` are written Y and N in the paper), and `[i,s]` is the counter symbol with
  value `i` on `s`. Each merged symbol is named by the first symbol of its class.
- Roles: `H`, `O`, and `G` name the roles of a block: `H` is the stable role, `O` the
  origin side of a carry, and `G` its destination side; `+k` and `-k` are the k-th
  blocks of Q+ and Q- (Section 3.2 of the paper).
- Initial configuration: that of URTM(13,7), with the symbol `s` under the head
  replaced by the counter `[i,s]` given below and every symbol replaced by the first
  symbol of its class.
- In the merges of URTM(4,41) and URTM(5,37), three pairs of quintuples become the
  same quintuple; each of them is listed once, as in the formalization.

### URTM(4,41)

- Blocks `(b+,b-) = (2,2)`; 142 quintuples.
- Merged classes: y = [6,n1]; y1 = [10,n]; n1 = [6,y1]; * = [3,n1]; $ = [8,b]; [3,y1] = [9,n]; [4,n1] = [9,y]; [7,n1] = [10,y]; [8,n] = [9,b].
- States and the roles they merge: state 0 = {H+1,G+2}; state 1 = {O+1,O+2,H-1,G-1,G-2}; state 2 = {G+1,H+2,O-1,O-2}; state 3 = {H-2}.
- Initial configuration: the head symbol `s` becomes `[10,s]`; initial state 2.
- The two halting quintuples of URTM(13,7) correspond to: state 2 reading [10,b]; state 3 reading [6,b].

### URTM(5,37)

- Blocks `(b+,b-) = (3,2)`; 145 quintuples.
- Merged classes: b = [3,n1] = [5,b]; n1 = [9,b]; [2,b] = [8,n1]; [2,y1] = [3,b] = [3,y1]; [3,$] = [5,y]; [4,b] = [7,b]; [4,y] = [9,n1]; [5,n] = [7,n1]; [6,b] = [9,*]; [6,n] = [9,y1].
- States and the roles they merge: state 0 = {H+1}; state 1 = {O+1,O+3,H-1,G-2}; state 2 = {G+1,G+2,H+3,O-1}; state 3 = {H+2,G+3,O-2}; state 4 = {O+2,G-1,H-2}.
- Initial configuration: the head symbol `s` becomes `[4,s]`; initial state 0.
- The two halting quintuples of URTM(13,7) correspond to: state 0 reading [4,b]; state 1 reading n1.

### URTM(6,30)

- Blocks `(b+,b-) = (3,3)`; 160 quintuples.
- Merged classes: y1 = [1,y]; n1 = [2,*]; * = [1,n]; $ = [1,b]; [2,b] = [4,n1]; [2,y] = [7,b]; [2,n] = [8,b]; [2,y1] = [8,y1]; [2,n1] = [8,$]; [2,$] = [8,y]; [3,b] = [4,y1]; [3,y1] = [4,b]; [3,n1] = [5,b] = [6,n]; [4,y] = [7,y]; [4,n] = [7,y1]; [4,*] = [8,n1]; [4,$] = [7,*]; [5,y] = [7,$]; [5,n] = [6,b]; [5,y1] = [8,n]; [5,n1] = [8,*]; [5,*] = [7,n1]; [5,$] = [7,n].
- States and the roles they merge: state 0 = {H+1,G+2,O-2,O-3}; state 1 = {O+1,O+2,H-2,G-3}; state 2 = {G+1,H+2,G+3}; state 3 = {H+3,O-1}; state 4 = {O+3,H-1,G-2}; state 5 = {G-1,H-3}.
- Initial configuration: the head symbol `s` becomes `[1,s]`; initial state 0.
- The two halting quintuples of URTM(13,7) correspond to: state 0 reading $; state 5 reading [2,b].

### URTM(7,28)

- Blocks `(b+,b-) = (4,3)`; 160 quintuples.
- Merged classes: b = [5,y1]; n1 = [1,*]; * = [5,n1]; [1,b] = [1,y] = [2,$]; [1,n] = [2,y]; [1,y1] = [3,b] = [6,b]; [1,$] = [2,n]; [2,b] = [6,n1]; [2,y1] = [4,b]; [2,*] = [4,y1]; [3,y] = [5,y]; [3,n] = [5,n]; [4,n1] = [5,b]; [5,*] = [7,b]; [5,$] = [7,y]; [6,y] = [7,n]; [6,n] = [7,y1]; [6,y1] = [7,n1]; [6,*] = [7,*]; [6,$] = [7,$].
- States and the roles they merge: state 0 = {H+1,G+4,O-1}; state 1 = {O+1,H-1}; state 2 = {G+1,H+4,O-2}; state 3 = {H+2,G+3}; state 4 = {O+2,G-2,H-3}; state 5 = {G+2,H+3,O-3}; state 6 = {O+3,O+4,G-1,H-2,G-3}.
- Initial configuration: the head symbol `s` becomes `[2,s]`; initial state 3.
- The two halting quintuples of URTM(13,7) correspond to: state 3 reading [2,b]; state 6 reading [2,b].

### URTM(8,21)

- Blocks `(b+,b-) = (4,4)`; 149 quintuples.
- Merged classes: b = [6,n]; y = [2,n1]; n = [6,b]; y1 = [2,b] = [3,y1]; n1 = [1,n] = [2,*]; * = [1,b]; $ = [1,y] = [3,n1]; [2,y] = [5,n1]; [2,n] = [5,b]; [2,y1] = [4,b]; [2,$] = [5,y]; [3,b] = [4,y1]; [3,y] = [5,n]; [3,n] = [5,y1]; [3,*] = [5,*]; [3,$] = [5,$].
- States and the roles they merge: state 0 = {H+1,G+2,G+4,O-2,O-4}; state 1 = {O+1,O+2,O+3,G-1,H-4}; state 2 = {G+1,H+3}; state 3 = {H+2,G+3,O-1,O-3}; state 4 = {H+4}; state 5 = {O+4,G-2,H-3}; state 6 = {H-1,G-4}; state 7 = {H-2,G-3}.
- Initial configuration: the head symbol `s` becomes `[1,s]`; initial state 3.
- The two halting quintuples of URTM(13,7) correspond to: state 3 reading *; state 7 reading y1.

## URTM(85,2)

Obtained from Morita's URTM(13,7) by the two-symbol conversion of the paper (3-bit
codes, path types, merging of equivalent states). The initial state is 2 and the
blank is 0.

- Encoding: a cell of URTM(13,7) is three consecutive cells; the symbols b, y, n, Y,
  N, *, $ of URTM(13,7) are written, from the left cell, as 000, 100, 101, 001, 010,
  110, 111. The head is on the leftmost of the three cells for the head cell of
  URTM(13,7).
- One step of URTM(13,7) is simulated in 3, 5, or 7 steps.
- The two halting quintuples of URTM(13,7) (reading the blank) correspond to state 2
  and state 7 reading 0.
