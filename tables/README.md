# Tables of the seven new URTMs

Plain-text quintuple tables of the seven new universal reversible Turing machines
of the paper. Each file starts with comment lines (`%`) that describe the machine,
followed by the states, the symbols, the blank, and one quintuple
`[p, s, t, d, q]` per line: in state `p` reading `s`, write `t`, move `d`
(`-` left, `+` right), and enter `q`. There are no halting quintuples; a machine
halts where no quintuple applies.

| File | Machine | Quintuples | In the paper |
|---|---|---|---|
| `urtm3-600.txt` | URTM(3,600) | 1,572 | Section 3.4 (too long to print) |
| `urtm4-42.txt` | URTM(4,42) | 141 | Appendix B |
| `urtm5-39.txt` | URTM(5,39) | 142 | Appendix B |
| `urtm6-30.txt` | URTM(6,30) | 160 | Appendix B |
| `urtm7-28.txt` | URTM(7,28) | 160 | Appendix B |
| `urtm8-21.txt` | URTM(8,21) | 149 | Appendix B |
| `urtm85-2.txt` | URTM(85,2) | 153 | Appendix A |

The tables are generated by the same tools and from the same construction
parameters as the tables in the Lean formalization. The five machines obtained by
symbol merging are given without their two halting quintuples, as in Appendix B;
the formalization proves universality for this form as well.
